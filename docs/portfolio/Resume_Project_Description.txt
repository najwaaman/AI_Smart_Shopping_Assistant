AI Smart Shopping Assistant | Python, Streamlit, scikit-learn

Built a seven-page Streamlit portfolio prototype combining product-text classification, historical retail analytics, product recommendations, customer prediction, segmentation, and model-insight views. Implemented a TF-IDF + Linear SVM classifier (95.80% accuracy on a separate 4,171-row product-text test split), Gradient Boosting repeat-purchase prediction, Ridge spending prediction, June-only item-item cosine recommendations, and three-cluster KMeans segmentation. Added cutoff-aware March/June data services, OIDC allowlist gating, synthetic-fixture tests, and explicit release exclusions for customer data and model artifacts. Evaluation keeps March training/fitting and June validation separate from the protected September holdout. The project is not deployed; browser, production, accessibility, and live identity-provider testing remain incomplete.
